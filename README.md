# 🚀 Node.js Practice Archive

These projects were built during my early Node.js learning phase in 2024, capturing my hands-on exploration of backend fundamentals.

---

## 📂 Projects Included

- **basic_node** – learning the very basics
- **http-server** – simple server experiments
- **express** – first steps with Express
- **module (ESM & CommonJS)** – figuring out modules
- **package_example** – playing around with npm packages
- **nodeperformance** – trying to understand performance
- **security-example** – basic security concepts
- **realtime_tracker** – experimenting with real-time ideas
- **videostreaming** – testing how streaming works
- **planets_project / NASA_Project** – API-based learning projects
- **chessgame / fisherman** – small logic-building apps
